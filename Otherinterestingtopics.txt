Version Control: A method for managing changes to documents, programs and
other types of information stored as computer files.
 
Git: A distributed version control system that is free and open source. It allows for
effective tracking and management of source code changes.
 
The Git Life Cycle: The three stages in Git - Working Directory, Staging Area, and
the Git Commit.

Git Commands: We covered the most basic commands such as git init , git
status , git add , git commit , git log , git diff , and also learned about
