## Resolving Merge Conflicts

Resolving Merge Conflicts

To resolve a merge conflict:

1. Edit the file to fix the conflicting changes. Be sure to remove the conflict markers.

2. Add the file to the staging area with:
git add .

3. Commit the fix with:
git commit .
